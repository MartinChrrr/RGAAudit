# Consigne de suivi du projet

## GitHub Project de référence

Le suivi fonctionnel de RGAAudit se fait dans le GitHub Project suivant :

- Dépôt : `MartinChrrr/RGAAudit`
- Project : [RGAAudit — Project 5](https://github.com/users/MartinChrrr/projects/5/views/1)

## Règle pour les demandes d’avancement

Lorsqu’une demande concerne l’avancement, une mise à jour, le backlog, les priorités ou la question « où en est le projet ? », consulter d’abord l’état actuel du GitHub Project et des issues associées.

La réponse doit se baser en priorité sur :

1. les cartes et leur colonne (`Todo`, `In progress`, `Done`, etc.) ;
2. l’ordre des épics et des user stories ;
3. les labels et champs personnalisés (`Temps`, `Difficulté`, `Priorité`) ;
4. les issues, pull requests et commits récents lorsqu’ils apportent un contexte utile.

Ne pas déduire l’avancement uniquement à partir des fichiers locaux. Si GitHub est inaccessible, le signaler explicitement et distinguer les informations vérifiées localement de celles qui n’ont pas pu être vérifiées.

Après cette vérification, résumer brièvement :

- ce qui est terminé ;
- ce qui est en cours ;
- le prochain objectif recommandé ;
- les blocages ou décisions attendus.

Cette consultation est obligatoire pour les demandes d’état du projet, mais n’est pas nécessaire pour une question purement technique sans lien avec le suivi du backlog.
